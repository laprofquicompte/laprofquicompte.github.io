📘 Rappel de cours : les suites numériques

Une suite numérique (un) est une liste ordonnée de nombres : à chaque rang n, on associe un nombre un.

  • Suite arithmétique : chaque terme s'obtient en ajoutant toujours le même nombre r (la raison) au précédent : un+1 = un + r. Formule directe : un = u0 + n × r.
  • Suite géométrique : chaque terme s'obtient en multipliant toujours le précédent par un même nombre q (la raison) : un+1 = q × un. Formule directe : un = u0 × qn.
  • Reconnaître la nature d'une suite : si un+1 − un est constant → arithmétique ; si un+1 ⁄ un est constant → géométrique.
  • Sens de variation (arithmétique) : si r > 0, croissante ; si r < 0, décroissante ; si r = 0, constante.
  • Sens de variation (géométrique) : dépend à la fois du signe de u0 et de la valeur de q (0 < q < 1 ou q > 1 ou q = 1).
  • Représentation graphique : arithmétique → points alignés ; géométrique → points qui suivent une croissance (ou décroissance) exponentielle selon q (jamais alignés, sauf cas particulier).
💡 Pourquoi ces 8 suites ? (à lire après avoir joué)
  • u0 = 2, r = 3 (2 ; 5 ; 8 ; 11) et u0 = 3, r = 2 (3 ; 5 ; 7 ; 9) : deux suites arithmétiques, piège classique de l'inversion de u0 et r — les deux nombres 2 et 3 sont les mêmes, mais leur rôle change tout.
  • u0 = 10, r = −4 : une suite arithmétique décroissante, pour équilibrer avec les exemples croissants.
  • u0 = 5, r = 0 : cas particulier d'une suite arithmétique constante.
  • u0 = 2, q = 3 : suite géométrique, croissante (u0 > 0 et q > 1) — elle suit une croissance exponentielle.
  • u0 = 4, q = 0,5 : piège de la raison décimale entre 0 et 1 — la suite est décroissante bien que tous les termes soient positifs.
  • u0 = −2, q = 3 : piège du premier terme négatif — avec q > 1 on pourrait croire la suite croissante, elle est en réalité décroissante.
  • u0 = 6, q = 1 : cas particulier d'une suite géométrique constante.
