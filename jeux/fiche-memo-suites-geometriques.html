Suites numériques & géométriques

À relire juste avant un QCM ou un jeu — pas un cours complet, juste l'essentiel.

Une suite, c'est quoi ?

Une liste ordonnée de nombres u0, u1, u2... où chaque terme a un rang n. On note un le terme de rang n.

Arithmétique

On ajoute toujours le même nombre r (la raison) au terme précédent.

un+1 = un + rrécurrence
un = u0 + n × rformule directe
Sens de variation
r > 0 croissante
r < 0 décroissante
r = 0 constante
Exemple Ton argent de poche : tu as 20 €, et tu économises 10 € chaque semaine. u0 = 20, r = 10 → semaine 5 : u5 = 20 + 5×10 = 70 €.

Géométrique

On multiplie toujours par le même nombre q (la raison) le terme précédent.

un+1 = q × unrécurrence
un = u0 × qnformule directe
Sens de variation
Si u0 > 0
q > 1 croissante
0 < q < 1 décroissante
Si u0 < 0
q > 1 décroissante
0 < q < 1 croissante
q = 1 constante (dans tous les cas)
Exemple Une vidéo qui buzz : 4 vues la 1ère heure, puis ×3 chaque heure. u0 = 4, q = 3 → 3h après : u3 = 4×33 = 108 vues.
🧠 Le réflexe un+1 − un constant ? → arithmétique (raison r) un+1 ÷ un constant ? → géométrique (raison q)
