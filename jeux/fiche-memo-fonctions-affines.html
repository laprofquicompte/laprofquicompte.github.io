Fonctions affines

À relire juste avant un exercice ou une évaluation — pas le cours complet, juste l'essentiel.

Une fonction affine, c'est quoi ?

Une fonction définie sur ℝ qui, à un nombre réel x, associe le nombre ax + b, avec a et b deux nombres réels. On note f(x) = ax + b.

⚠️ a est le coefficient directeur, b l'ordonnée à l'origine. Ne pas les inverser !

Représentation graphique

Dans un repère, la représentation graphique d'une fonction affine est une droite non parallèle à l'axe des ordonnées. Réciproquement, toute droite non parallèle à cet axe est la représentation graphique d'une fonction affine.

Méthode — tracer la droite
  • Calculer les coordonnées de deux points et les placer dans un repère
  • Ou utiliser directement le coefficient directeur et l'ordonnée à l'origine
Exemple f(x) = -x + 6 → coefficient directeur : -1 ; ordonnée à l'origine : 6.

Sens de variation

Soit f(x) = ax + b une fonction affine. Son sens de variation dépend uniquement du signe de a.

Théorème — sens de variation
a > 0 f croissante
a < 0 f décroissante
a = 0 f constante
Exemples f(x) = 2x + 1 : a = 2 > 0 → croissante.
g(x) = -3x + 4 : a = -3 < 0 → décroissante.
h(x) = 5 : a = 0 → constante.

Cas particuliers

Deux cas particuliers de la fonction affine f(x) = ax + b selon les valeurs de a et b.

Si b = 0 → f(x) = axlinéaire
Si a = 0 → f(x) = bconstante
Exemple g(x) = -²⁄₇ x est une fonction linéaire : coefficient directeur -²⁄₇, ordonnée à l'origine 0.
⚠️ Une fonction linéaire est un cas particulier de fonction affine (b = 0) — sa droite passe toujours par l'origine du repère.

Taux d'accroissement

Soit f(x) = ax + b et deux nombres réels distincts m et n. Alors :

a = (f(m) − f(n)) / (m − n)taux d'accroissement

Pour trouver le coefficient directeur d'une droite, on choisit deux points et on calcule le rapport entre la différence des images et la différence des deux nombres de départ.

Exemple Coefficient directeur de (AB), avec A(1 ; 3) et B(4 ; 5) :
(5 − 3) / (4 − 1) = 2/3
