Q1

Une fonction affine f définie sur ℝ s'écrit sous la forme :

CorrectionUne fonction affine est définie par f(x) = ax + b, où a et b sont deux nombres réels.
Q2

Soit f(x) = 3x - 4. Que vaut f(2) ?

Correctionf(2) = 3×2 - 4 = 6 - 4 = 2.
Q3

Dans f(x) = -5x + 7, le coefficient directeur est :

CorrectionLe coefficient directeur est le nombre a devant x, ici -5. 7 est l'ordonnée à l'origine.
Q4

Soit g(x) = 6x. Quel type de fonction est g ?

Correctiong(x) = 6x est de la forme ax + b avec b = 0 : c'est une fonction linéaire (cas particulier de fonction affine).
Q5

Soit h(x) = 9. Quel type de fonction est h ?

Correctionh(x) = 9 correspond à a = 0 et b = 9 : c'est une fonction constante.
Q6

Soit f(x) = 4x - 1. Comme a = 4 > 0, la fonction f est :

CorrectionSi a > 0, la fonction affine est croissante. Ici a = 4 > 0.
Q7

Soit g(x) = -2x + 3. La fonction g est :

CorrectionIci a = -2 < 0, donc g est décroissante.
Q8

La représentation graphique d'une fonction affine dans un repère est toujours :

CorrectionLa représentation graphique d'une fonction affine est une droite non parallèle à l'axe des ordonnées.
Q9

Une droite passe par les points A(1 ; 3) et B(3 ; 7). Son coefficient directeur est :

Correctiona = (f(m) - f(n)) / (m - n) = (7 - 3) / (3 - 1) = 4/2 = 2.
Q10

Sur un graphique, une droite coupe l'axe des ordonnées au point (0 ; 5). Que peut-on en déduire ?

CorrectionLe point où la droite coupe l'axe des ordonnées donne directement l'ordonnée à l'origine b. Ici b = 5.
